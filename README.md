# BD-mis-libros

## Descripción

Este proyecto empezó como una base de datos para registrar los libros que voy leyendo.
Ahora está evolucionando hacia una aplicación en Java con interfaz gráfica para poder gestionar y consultar la información de forma más cómoda.

La idea es conectar una base de datos MySQL con una aplicación que permita interactuar con los datos de manera visual.

---

## Qué estoy trabajando

* **SQL y bases de datos**

  * Diseño de tablas
  * Consultas (SELECT, JOIN, etc.)
  * Vistas
  * Organización de datos

* **Java**

  * Conexión a base de datos (JDBC)
  * Lógica de aplicación
  * Manejo de datos desde código

* **Interfaz gráfica**

  * Construcción de GUI (JavaFX)
  * Interacción usuario-aplicación
  * Visualización de datos

* **Flujo completo**

  * Guardar datos
  * Consultarlos
  * Filtrarlos
  * Mostrarlos en una interfaz

---

## Estructura

* `Mis_libros.sql` → Base de datos completa (tablas, datos y vistas)
* CSV → Datos originales (autores, países, géneros, libros)
* Código Java → Lógica + conexión a BD
* GUI → Interfaz para interactuar con todo

Más que el resultado final, el foco está en aprender a conectar varias piezas: base de datos + backend en Java + una interfaz usable.
